# 剪贴记录 · 轻量桌面界面规范

使用 ui-ux-pro-max 的设计系统检索、交互检索和焦点规范。视觉按用户最新要求参考 Apple 的浅色界面，保留 Windows 11 原生窗口效果。技术栈保持 WinForms，不使用网站式大标题、营销配色或额外网页字体。

## 窗口与布局

- 主窗口默认 520 × 560px，最小 520 × 420px。
- 设置增加“固定到底部”开关，启用后窗口宽度等于当前屏幕工作区宽度、高度 260px，贴工作区底边并避开任务栏。关闭后恢复切换前的位置和尺寸；原有置顶与失焦收起规则保留。
- 底部模式将标题、搜索、类型筛选、重置和窗口按钮合并成 44px 顶部单行，搜索区 248px、类型筛选区 256px，不随屏幕宽度拉伸；空白放在筛选区与最右侧窗口按钮之间。隐藏原类型行、底部工具栏及滚动条占位。
- 底部模式的列表使用单行4:3 卡片，不显示滚动条；滚轮和横向触控板滚动，键盘左右切换。操作按钮移至卡片右上方横排，文字置于按钮下方；图片等比例显示，下方展示尺寸。普通模式维持原布局、纵向卡片和右侧滑块。
- 列表取消原生滚动条占位，使用 6px 灰色圆角滑块覆盖右侧内容；不绘制轨道、背景、阴影或边框，悬停时颜色加深，内容不足一屏时隐藏。滑块只拦截自身区域的鼠标事件。
- 顶部为 32px 单行操作栏：10pt 普通字重标题，以及置顶、设置、最小化、收起四个 32 × 28px 图标按钮。移除顶部应用图标、操作提示和记录统计。
- 列表上方固定 44px 分段选择区域，四项等宽：“全部、文本、图片、文件”。浅蓝底色配蓝底白字选中块，支持键盘焦点及方向键切换，不随列表滚动。
- 底部为 54px 单行工具栏，仅包含圆角搜索框和重置按钮，搜索框占据剩余宽度。使用搜索图标与“搜索记录”占位文字，获得焦点时显示淡蓝圆角边线。出错时展开 24px 反馈行。
- 取消日期筛选和分页，记录总数通过设置中的三个分段按钮选择 20、50、100 条，默认 100 条；保存设置后立即生效，启动和新增记录时按上限清理。一次显示全部筛选结果，通过列表滚动查看。置顶记录计入上限，仅影响显示顺序，淘汰按最新复制时间计算；界面明确提示超限会删除较早记录。
- 系统窗口框架样式保留，系统标题栏通过 WM_NCCALCSIZE 移除。
- 使用 DWM 开启非客户区渲染，边缘扩展 1px；Windows 11 请求系统圆角。
- 不使用透明分层窗口、窗口 Region 裁剪或额外阴影窗口。
- 普通窗口卡片行高 104px，底部模式可见卡片宽高严格为 4:3（扣除卡片外间距），圆角 12px、按钮圆角 8px。卡片常驻细边线，悬停边线加深，选中时浅蓝底与蓝色边框；工具栏为白色，与淡蓝列表底色形成层次。文本保留换行，时间、来源在完整预览中查看。
- 列表文字使用常规字重与灰度抗锯齿。按字体实际高度加 4px 行间距（随绘制 DPI 调整）逐行排版，仅绘制能完整容纳的行，末行超出时显示省略号，避免底部裁切字形。
- 图片卡片左侧提供 116 × 72px 预览区域，等比例居中显示；右侧显示图片类型及原始尺寸。缩略图最大 240 × 144px，内存缓存上限 48 张。
- 系统操作图标使用 Segoe MDL2 Assets，程序图标仍用于 EXE、托盘及预览窗口。

## 开发字段翻译窗口

- 窗口独立于剪贴板，通过 Alt+2 或托盘菜单打开；默认 600 × 533px，最小 520 × 500px。默认输入与结果区域高度各减少约 30%，保持原 45:55 分配及其他工具栏尺寸；每次打开或恢复窗口后自动聚焦第一个输入文本框。
- 沿用主窗口 32px 单行小标题栏、四个 32 × 28px 置顶/设置/最小化/收起图标和 DWM 系统圆角、阴影、边缘缩放。
- 翻译方向使用同款 `SegmentTab` 浅蓝底、蓝底白字选中块；原生文本编辑框置于白色圆角表面，内边距 12px，聚焦时使用搜索框同款淡蓝边线。
- DeepSeek API 配置首次自动展开，之后通过顶部设置图标展开；配置输入使用浅灰圆角底色。底部命名格式使用五个等宽的中文分段按钮：小驼峰、大驼峰、下划线、大写下划线、短横线，当前选项蓝底白字，悬停展示命名示例；英译中时禁用整组。格式按钮随窗口宽度伸缩，右侧保留独立的“复制结果”按钮，不再使用下拉菜单。
- 命名格式点选后立即转换结果框中的英文内容，逐行处理并保留空行，不重复调用翻译接口；基于原始英文结果重新组合单词，避免格式来回切换丢失分词边界。请求返回后使用当前最新选择，中文结果不参与命名转换。
- 保持现有配色及 Microsoft YaHei UI 10pt 正文字体、9pt 次要文字；翻译是唯一蓝色主要操作，取消和复制保持次要按钮外观。

## 托盘菜单与应用图标

- 参考用户提供的菜单截图，采用白色表面、细分隔线和充足行间留白；按打开入口、工具操作、退出分组，不增加无关入口。
- 菜单最小宽度约 260px，沿用 9pt 中文字体；打开入口的快捷键靠右，标题和快捷键使用次要文字颜色。
- 鼠标悬停和键盘选中使用浅灰圆角底色，开机启动使用蓝色勾选标记。每次展开菜单同步当前开机启动状态。
- 使用原生 ContextMenuStrip 的键盘、焦点、自动关闭和阴影行为，通过 DWM 请求 Windows 11 圆角，不添加独立菜单窗口。
- 应用图标采用 #F5F5F7 浅色剪贴板线条与 #374151 细深色外描边，适配深浅任务栏；背景和内部留白完全透明，不添加底板。16px 主线宽约 1px、外轮廓约 1.5px，24px 主线宽约 1.125px，提供 16/24/32/48/64/128/256px ICO 帧。

## 交互

- 记录悬停边框变深，点击直接粘贴；不通过缩放制造位移。
- 当前选中记录使用浅蓝背景与轻量圆角边框，键盘焦点加深边框。去掉矩形虚线焦点框，行内容使用独立位图缓冲完整绘制。
- 按钮保留 Tab、Enter、Space 和可见键盘焦点提示。
- 置顶状态以固定/取消固定的不同图标、蓝色背景和悬停提示表达，同时更新无障碍名称。
- 卡片右侧竖排三个 32 × 28px 图标按钮：更多、置顶/取消置顶、删除，间距 2px；绘制与点击共用按钮区域。悬停显示圆角底色与用途提示，置顶按钮常驻淡蓝底色与蓝色图标，删除按钮仅在悬停时显示淡红底色与红色图标。
- 卡片操作图标改用统一细线矢量绘制：16px 图标、1px 描边、圆头圆角，不使用字体字形或加粗效果。更多为三个细圆点，图钉未置顶时略微倾斜、置顶后直立，删除为轮廓垃圾桶；更多菜单中的图标同步减细描边。图标按 DPI 缩放并限制在原按钮内，点击区域保持不变。
- “…”菜单使用独立的紧凑布局：白色表面、12px 圆角细边框、6px 外留白，三行操作各高 36px、间距 2px，整体宽约 224px。每行左侧为 18px 灰色线性图标，图文间隔 10px，左右内边距 12px，字体与卡片一致为 10pt；悬停和键盘选中显示 8px 圆角浅灰底色。尺寸随字体与系统 DPI 缩放，不显示勾选栏或系统图片色带。
- 菜单只保留查看完整内容、复制和粘贴，靠按钮右侧对齐，保留右键入口，并支持 Shift+F10 和菜单键；Ctrl+P 切换选中记录的置顶，Delete 删除选中记录，点击内容仍直接粘贴。
- 置顶、失焦收起、内部弹出面板、搜索筛选和记录数据流保持原有行为。

## Flutter 迁移说明

当前界面实现位于 `lib/`，配色、圆角和字体沿用以上规范。原有 WinForms 控件及绘制类保留作迁移参考，当前打包流程使用 Flutter Windows runner。窗口消息、托盘、剪贴板和快捷键由 `windows/native/` 提供。以上涉及 WinForms 控件名和绘制实现的说明属于旧版实现记录，Flutter 的实际布局与交互仍需桌面运行验收。
