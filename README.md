# 剪贴记录

Windows 桌面剪贴板历史工具，使用系统 .NET Framework 4.x 和 WinForms，无第三方依赖。

字体、统一行高和浅灰圆角悬停底色；选中记录后 Shift+F10 也可打开菜单。预览中显示记录时间、类型和来源。
- 置顶记录在当前筛选结果中优先显示，并带有蓝色图钉；置顶状态在重启后保留，重复合并时沿用。删除会移除该记录的所有历史版本及图片副本，也可删除置顶记录；文件记录指向的原始文件不会被删除。
- 默认 Ctrl+Alt+V 打开历史，可在窗口右上角或托盘的“设置”中修改；冲突时会提示并保留原快捷键。
- 设置中可配置开机启动和重复合并间隔（0–60 秒，0 表示关闭合并）。
- 设置中提供“固定到底部”开关，保存后生效并在重启后保留。开启后，剪贴板窗口固定在当前屏幕工作区底部，通栏宽度、260px 高，不覆盖任务栏；禁止拖动、缩放及最大化。关闭开关后恢复本次切换前的普通窗口位置和大小。
- 底部模式中，标题、搜索、类型筛选、重置及窗口按钮合并到顶部一栏；搜索和类型筛选使用紧凑固定宽度，剩余空白不拉伸筛选。记录为单行4:3 卡片，隐藏滚动条及其占位，支持滚轮横向滚动、触控板横向滚动和左右方向键；更多、置顶、删除三个按钮横排在卡片顶部。搜索、类型筛选、最近 100 条上限、粘贴和原有窗口置顶/失焦收起行为保持不变。开发字段翻译窗口不受此开关影响。
- 设置中的“清除缓存”在确认后立即删除所有日期的未置顶记录及图片副本，保留置顶记录及其图片，无需再保存设置。保留快捷键等配置、开机启动、系统剪贴板内容和文件记录指向的原始文件；之后的新复制仍会正常记录。
- 主窗口默认 520 × 560px，最小 520 × 420px，无系统标题栏，顶部为 32px 单行小标题和系统图标按钮；可拖动顶部空白或应用名称移动，拖动边缘调整大小。
- 列表右侧预留独立的 12px 滚动区域，圆角滑块位于卡片外部，不显示轨道背景、阴影或描边；支持滚轮、键盘和拖动，内容不足一屏时隐藏滑块，卡片宽度保持不变。
- 顶部提供窗口置顶、设置、最小化和收起按钮。窗口未置顶时，切换到外部窗口会自动收起到托盘；窗口置顶时失去焦点或点击记录粘贴均保持显示。手动收起仍有效。窗口置顶状态仅在当前运行期间保留。
- 类型通过顶部标签切换，可与搜索组合使用。设置、预览和菜单属于程序内操作，不触发误收起。
- EXE、窗口、托盘使用统一的多尺寸线性剪贴板图标，浅色主线条配细深色外描边，透明背景，无彩色底板，在深浅任务栏上均可辨认。
- 界面采用淡蓝背景、白色工具栏与卡片、深蓝文字和蓝色分段选中态；底部使用带搜索图标的圆角输入框和圆角按钮，选中及键盘焦点采用轻量蓝色提示。窗口仍通过 Windows DWM 提供系统阴影及 Windows 11 圆角。
- 图片记录显示等比例缩略图和原始尺寸；仅为可见记录加载缩略图，内存最多缓存 48 张，清除缓存或退出时释放。原图保留用于预览与粘贴。
- 记录卡片突出多行内容，移除类型徽标和时间、来源摘要。主窗口不再常驻显示操作提示、保存数量、粘贴目标或成功状态；错误发生时才展开底部提示。
- 关闭窗口后留在托盘继续记录，托盘菜单可选择开机启动、打开数据目录和退出。
- 托盘右键菜单采用白色背景、细分隔线和浅灰圆角悬停；打开剪贴板、工具操作、退出分组展示，快捷键靠右显示，开机启动以勾选表示。
- 支持单实例，重复运行会打开已有窗口。

## 生成 EXE

双击项目根目录的 `打包.bat` 即可生成 EXE，窗口会显示结果，失败时保留错误信息。程序正在运行时，请先从托盘退出再打包。

也可以在项目目录手动执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```
## 使用

1. 启动 EXE，然后正常复制文本、图片或文件。
2. 在目标软件中点击需要粘贴的输入框。
3. 按配置的快捷键（默认 Ctrl+Alt+V）打开历史；使用顶部类型标签和底部搜索框筛选后点击一条记录。
4. 内容恢复到剪贴板，原窗口重新获得焦点并接收 Ctrl+V。
5. 关闭历史窗口后继续在托盘运行；通过托盘的“退出”结束记录。

全局快捷键冲突时，状态栏会提示，可双击托盘打开。目标应用以管理员身份运行时，Windows 可能阻止普通权限程序发送粘贴按键，可以手动 Ctrl+V，或以相同权限运行工具。

## 开发字段翻译

按 **Alt+2** 或点击托盘菜单的“开发字段翻译”打开独立窗口。该窗口不依附剪贴板历史窗口；关闭后收起，重新打开保留当前输入和结果。每次打开或恢复窗口后，焦点自动放到第一个输入文本框。若 Alt+2 被其他程序占用，启动时会有托盘提示，仍可从托盘菜单打开。

1. 在 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys)创建 API Key。
2. 点击翻译方向分段器右侧的“配置”，在弹窗中填写 DeepSeek API Key 和模型名称，点击“保存配置”。首次使用会自动打开配置弹窗；取消不修改原配置，保存失败会在弹窗中提示。默认模型为 `deepseek-flash`，也可填写 `deepseek-v4-pro`。模型名称以 [DeepSeek 官方文档](https://api-docs.deepseek.com/zh-cn/)为准。
## 数据存储

默认目录：`%LOCALAPPDATA%\WinTool\ClipboardHistory`

- `records\yyyy-MM-dd.jsonl`：按本地复制日期保存，包含完整文本、时间、来源窗口和图片/文件引用。
- `images\*.png`：图片的独立副本。
- `settings.json`：快捷键和重复合并间隔；开机启动状态直接读取当前用户的 Windows 注册表项。
