# 剪贴记录

Windows 桌面剪贴板历史工具，使用系统 .NET Framework 4.x 和 WinForms，无第三方依赖。

## 功能

- 程序运行期间自动保存文本、图片和文件列表。默认 3 秒内相同内容合并为一条，更新时间、来源和粘贴格式；超出间隔新增记录。
- 最多保留最近 100 条记录，按最新复制时间淘汰更早记录及其图片副本；置顶记录也计入上限，置顶仅改变显示顺序。启动时会将原有超额历史清理至 100 条，退出、重启后保留范围不变。
- 取消日期筛选和分页；“全部、文本、图片、文件”四个类型标签固定在列表上方，底部仅保留搜索框和重置按钮，支持内容、文件名和来源窗口搜索。
- 一次显示全部筛选结果，通过滚动查看最近 100 条历史。列表整块双缓冲，缓存文字排版，普通滚轮每个刻度移动一张卡片；新复制记录刷新时保留当前滚动位置和选中记录。
- 点击一条记录，切回之前的窗口并发送 Ctrl+V；键盘选中后 Enter 也可粘贴。
- 卡片右侧依次提供“更多、置顶/取消置顶、删除”三个图标按钮，悬停显示用途；点击置顶或删除直接操作当前单条记录。选中记录后 Ctrl+P 切换记录置顶，Delete 删除。
- 卡片操作使用细线矢量图标，去掉字体图标的粗重效果：细圆点、轮廓图钉、轮廓垃圾桶。置顶后图钉直立并保持蓝色，更多菜单的图标也采用细描边。
- 点击“…”或右键打开紧凑的白色圆角菜单，三行操作采用左侧线性图标、右侧文字：查看完整内容、复制到剪贴板及粘贴到目标窗口。菜单使用卡片同款 10pt 字体、统一行高和浅灰圆角悬停底色；选中记录后 Shift+F10 也可打开菜单。预览中显示记录时间、类型和来源。
- 置顶记录在当前筛选结果中优先显示，并带有蓝色图钉；置顶状态在重启后保留，重复合并时沿用。删除会移除该记录的所有历史版本及图片副本，也可删除置顶记录；文件记录指向的原始文件不会被删除。
- 默认 Ctrl+Alt+V 打开历史，可在窗口右上角或托盘的“设置”中修改；冲突时会提示并保留原快捷键。
- 设置中可配置开机启动和重复合并间隔（0–60 秒，0 表示关闭合并）。
- 设置中提供“固定到底部”开关，保存后生效并在重启后保留。开启后，剪贴板窗口固定在当前屏幕工作区底部，通栏宽度、260px 高，不覆盖任务栏；禁止拖动、缩放及最大化。关闭开关后恢复本次切换前的普通窗口位置和大小。
- 底部模式中，标题、搜索、类型筛选、重置及窗口按钮合并到顶部一栏；搜索和类型筛选使用紧凑固定宽度，剩余空白不拉伸筛选。记录为单行4:3 卡片，隐藏滚动条及其占位，支持滚轮横向滚动、触控板横向滚动和左右方向键；更多、置顶、删除三个按钮横排在卡片顶部。搜索、类型筛选、最近 100 条上限、粘贴和原有窗口置顶/失焦收起行为保持不变。开发字段翻译窗口不受此开关影响。
- 设置中的“清除缓存”在确认后立即删除所有日期的未置顶记录及图片副本，保留置顶记录及其图片，无需再保存设置。保留快捷键等配置、开机启动、系统剪贴板内容和文件记录指向的原始文件；之后的新复制仍会正常记录。
- 主窗口默认 520 × 560px，最小 520 × 420px，无系统标题栏，顶部为 32px 单行小标题和系统图标按钮；可拖动顶部空白或应用名称移动，拖动边缘调整大小。
- 列表右侧预留独立的 12px 滚动区域，圆角滑块位于卡片外部，不显示轨道背景、阴影或描边；支持滚轮、键盘和拖动，内容不足一屏时隐藏滑块，卡片宽度保持不变。
- 顶部提供窗口置顶、设置、最小化和收起按钮。窗口未置顶时，切换到外部窗口会自动收起到托盘；窗口置顶时失去焦点或点击记录粘贴均保持显示。手动收起仍有效。窗口置顶状态仅在当前运行期间保留。
- 类型通过顶部标签切换，可与搜索组合使用。设置、预览和菜单属于程序内操作，不触发误收起。
- EXE、窗口、托盘使用统一的多尺寸线性剪贴板图标，浅色主线条配细深色外描边，透明背景，无彩色底板，在深浅任务栏上均可辨认。
- 界面采用淡蓝背景、白色工具栏与卡片、深蓝文字和蓝色分段选中态；底部使用带搜索图标的圆角输入框和圆角按钮，选中及键盘焦点采用轻量蓝色提示。窗口仍通过 Windows DWM 提供系统阴影及 Windows 11 圆角。
- 图片记录显示等比例缩略图和原始尺寸；仅为可见记录加载缩略图，内存最多缓存 48 张，清除缓存或退出时释放。原图保留用于预览与粘贴。
- 记录卡片突出多行内容，移除类型徽标和时间、来源摘要。主窗口不再常驻显示操作提示、保存数量、粘贴目标或成功状态；错误发生时才展开底部提示。
- 关闭窗口后留在托盘继续记录，托盘菜单可选择开机启动、打开数据目录和退出。
- 托盘右键菜单采用白色背景、细分隔线和浅灰圆角悬停；打开剪贴板、工具操作、退出分组展示，快捷键靠右显示，开机启动以勾选表示。
- 支持单实例，重复运行会打开已有窗口。

## 生成 EXE

双击项目根目录的 `打包.bat` 即可生成 EXE，窗口会显示结果，失败时保留错误信息。程序正在运行时，请先从托盘退出再打包。

也可以在项目目录手动执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

输出 `dist\winTool.exe`。可以将这个 EXE 复制到固定目录运行，不需要安装 .NET SDK。支持已启用 .NET Framework 4.x 的 Windows 10/11。

`version.txt` 保存最近一次成功打包的版本，初始为 `1.0.0.0`。每次通过 `打包.bat` 或 `build.ps1` 成功打包，最后一位自动加 1（首次为 `1.0.0.1`），失败时不递增。版本同步写入 EXE 的程序集、文件、产品版本及程序清单，在设置窗口标题和 EXE 文件属性中可查看。自动生成的版本信息与清单位于 `dist\build`，只需分发 EXE。

图标位于 `assets\clipboard.ico`，包含 16/24/32/48/64/128/256px 尺寸，构建时嵌入 EXE，无需随 EXE 分发图片文件。`assets\create-icon.ps1` 可重新生成图标资产，`assets\clipboard.png` 为预览图。

## 使用

1. 启动 EXE，然后正常复制文本、图片或文件。
2. 在目标软件中点击需要粘贴的输入框。
3. 按配置的快捷键（默认 Ctrl+Alt+V）打开历史；使用顶部类型标签和底部搜索框筛选后点击一条记录。
4. 内容恢复到剪贴板，原窗口重新获得焦点并接收 Ctrl+V。
5. 关闭历史窗口后继续在托盘运行；通过托盘的“退出”结束记录。

全局快捷键冲突时，状态栏会提示，可双击托盘打开。目标应用以管理员身份运行时，Windows 可能阻止普通权限程序发送粘贴按键，可以手动 Ctrl+V，或以相同权限运行工具。

## 开发字段翻译

按 **Alt+2** 或点击托盘菜单的“开发字段翻译”打开独立窗口。该窗口不依附剪贴板历史窗口；关闭后收起，重新打开保留当前输入和结果。每次打开或恢复窗口后，焦点自动放到第一个输入文本框。若 Alt+2 被其他程序占用，启动时会有托盘提示，仍可从托盘菜单打开。

1. 在 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys)创建 API Key。
2. 点击翻译方向分段器右侧的“配置”，在弹窗中填写 DeepSeek API Key 和模型名称，点击“保存配置”。首次使用会自动打开配置弹窗；取消不修改原配置，保存失败会在弹窗中提示。默认模型为 `deepseek-flash`，也可填写 `deepseek-v4-pro`。模型名称以 [DeepSeek 官方文档](https://api-docs.deepseek.com/zh-cn/)为准。
3. 选择“中文 → 英文字段”或“英文字段 → 中文含义”；生成英文字段时，直接点选底部的“小驼峰、大驼峰、下划线、大写下划线、短横线”五个中文按钮，当前格式蓝色高亮，悬停可查看格式示例；英译中时禁用这组按钮。
4. 每行输入一个字段，点击“翻译”或按 Ctrl+Enter。生成英文结果后，点选格式按钮会立即在结果框中逐行转换，保留空行，不重新请求翻译；请求过程中切换格式，返回后也按最新选择显示。完成后可选择文本复制，或点击“复制结果”复制全部。

例如输入“用户名称”“创建时间”，点选“小驼峰”后，预期得到 `userName`、`createdAt` 等字段名。翻译由模型生成，同一含义的命名可能不同。请求期间可以取消；关闭窗口也会取消请求。请求超时或失败会在窗口底部提示，可再次翻译。

接口采用 [DeepSeek Chat API](https://api-docs.deepseek.com/api/create-chat-completion/)，固定调用 `https://api.deepseek.com/chat/completions`，使用 Bearer API Key 鉴权；字段翻译关闭深度思考，以非流式方式获取结果。仅点击翻译时将当前输入及翻译要求发送至 DeepSeek，不自动读取或提交剪贴板历史。调用按所选模型的账户计费规则执行。

翻译配置独立保存至数据目录中的 `deepseek-translation.json`，API Key 通过 Windows DPAPI 使用当前用户凭据加密，不能直接复制给其他 Windows 用户解密使用。切换服务后需重新填写 DeepSeek API Key，旧的 `translation.json` 不读取、不删除。剪贴板设置中的 Alt+2 保留给翻译功能；若旧配置已经使用 Alt+2 打开历史，需将历史快捷键改为其他组合。

翻译窗口与剪贴板共享浅灰背景、白色圆角输入区、分段标签、按钮与字体。顶部为单行小标题及置顶、最小化、收起三个图标，支持标题拖动、边缘缩放、Windows 11 圆角与阴影。翻译方向分段器固定宽度，右侧为“配置”入口；API Key 和模型在独立弹窗中编辑。输入和结果文本框隐藏滚动条，命名格式通过底部圆角按钮选择。默认窗口为 600 × 533px，两个文本区域高度比原布局各减少约 30%，其他工具栏尺寸不变。

手动验收：验证 Alt+2 和托盘入口只唤起同一个翻译窗口；窗口最小化后可唤起；双向翻译、五种命名格式及多行字段可用；空配置、无效密钥、错误模型、断网、超时和取消均有提示；关闭后可重开；复制结果可用；退出时请求和窗口结束。重启后确认密钥及模型配置保留，并核对原剪贴板监听、粘贴和设置功能。

界面验收：并排打开剪贴板和翻译窗口，核对标题栏、图标、分段标签、圆角输入及按钮风格；验证置顶、标题拖动、边缘缩放、收起、配置弹窗的保存/取消/Esc、命名菜单和 Tab 键焦点。放大窗口后分段器不应拉伸，最小尺寸时“配置”入口仍可见。检查长文本的键盘导航、选择和复制，确认输入与结果不显示滚动条。分别在 100%/150%/200% 缩放及最小窗口尺寸下检查输入、输出和设置文字无截断。

## 数据存储

默认目录：`%LOCALAPPDATA%\WinTool\ClipboardHistory`

- `records\yyyy-MM-dd.jsonl`：按本地复制日期保存，包含完整文本、时间、来源窗口和图片/文件引用。
- `images\*.png`：图片的独立副本。
- `settings.json`：快捷键和重复合并间隔；开机启动状态直接读取当前用户的 Windows 注册表项。

合并通过追加同一记录的最新版本持久保存；读取时只显示最新版本，100 条上限按唯一记录计算。跨午夜合并时，记录归入最新复制日期。启动及新增记录时检查数量，超额时保留最近 100 条的最新日志版本、删除其余版本和未被引用的图片副本，不影响设置、翻译配置或文件记录指向的原文件。文本按完整纯文本比较（不去除空白）；文件按完整路径集合比较；图片按 PNG 内容指纹比较。

文件记录保存原始路径，不备份文件内容；原文件删除或移动后无法从该路径粘贴。文本同时保留可用的 HTML / RTF 格式。应用专有对象格式不在当前支持范围。退出期间的复制不会被记录；Windows 不提供过去未被本工具捕获的历史。

剪贴板历史记录仅存本机；翻译窗口中主动提交的字段会发送至 DeepSeek。文本日志是明文，复制的密码等敏感文本也会被记录。备份时先从托盘退出程序，再复制整个数据目录。

在设置中勾选“登录 Windows 后自动启动”并保存，或直接开启托盘中的“开机启动”。当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下写入 `winTool` 项，命令为带引号的当前 EXE 完整路径加 `--tray`；登录后在托盘运行，不弹出主窗口。关闭开关会删除启动项。已启用时，改名或移动 EXE 后手动运行一次会更新路径，同时迁移旧的 `WinToolClipboardHistory` 项；手动关闭的状态不会被重新开启。

## 手动验收

1. 在 3 秒内连续复制相同文本，确认只有一条记录、时间更新；等待超过 3 秒再复制，确认新增记录。重启后核对合并仍然有效。
2. 复制多行中文、富文本、截图和多个文件，分别预览、粘贴。
3. 在记事本输入框定位光标，Ctrl+Alt+V 后点击文本，确认粘贴位置正确且不新增自身恢复的记录。
4. 切换类型及搜索条件，核对筛选结果；取消筛选后可连续滚动查看最多 100 条记录，没有日期筛选和分页按钮。
5. 关闭窗口后再次复制，双击托盘确认记录；托盘退出后确认进程结束。
6. 文件删除后点击对应记录，确认明确提示文件不存在。
7. 重复启动程序，确认只有一个实例；检查托盘开机启动可开启和关闭。
8. 设置新快捷键，确认立即生效且旧快捷键释放；尝试被占用的快捷键，确认提示冲突、原快捷键仍可用；重启后确认配置保留。
9. 设置合并间隔为 0，确认重复复制产生独立记录；再开启合并，分别验证文本、图片、文件，以及短时间 A→B→A 的情形。
10. 验证跨午夜合并只归入最新日期；底部工具栏在最小窗口宽度下保持一行；拖动、边缘缩放、收起和最小化均可用。
11. 核对默认窗口宽度为 520px，底部仅有搜索和重置；类型筛选、搜索和重置可正常使用。
12. 未置顶时切换到记事本，确认历史窗口自动收起而后台仍记录；置顶后再次切换，确认窗口保持显示；取消置顶后再次切换，确认恢复自动收起。
13. 在未置顶状态打开设置、文本/图片预览和右键菜单，确认操作时不会误收起；置顶后点击记录，确认目标窗口接收粘贴而历史保持显示。
14. 新版构建后检查资源管理器、预览窗口及托盘的程序图标；主窗口顶部只显示小标题和四个操作图标。
15. 在 Windows 11 桌面核对系统窗口圆角和阴影，检查拖动、边缘缩放、最小化、重新打开及置顶后的效果；使用 Tab 检查按钮焦点提示，鼠标移动到记录上核对悬停边框。
16. 核对顶部只有一行，正常记录和筛选时不显示固定状态栏；复制多行中文，确认卡片保留换行；点击“…”、右键或 Shift+F10 打开菜单，确认预览可查看时间与来源，点击卡片内容仍直接粘贴。
17. 右键托盘，核对菜单分组、留白、悬停和快捷键靠右显示；使用方向键、Enter、Esc 验证菜单操作；设置中更改快捷键或开机启动后，再次打开菜单确认同步更新。
18. 在深色、浅色任务栏和资源管理器中检查 16/24/32px 线性图标，确认浅色主线与细深色外描边均清晰、背景透明；在 Windows 11 上确认托盘菜单圆角和阴影、高 DPI 下文字与快捷键不截断。
19. 分别显示空列表、不足一屏和多屏记录，确认滑块仅在溢出时出现，卡片宽度始终不变；滚轮、方向键、PageUp/PageDown、Home/End、拖动滑块均能到达首尾，拖动滑块不触发粘贴；筛选、添加记录和缩放窗口后核对滑块位置和大小。
20. 切换四个类型标签，确认只显示对应类型，选中标签为蓝底白字圆角块；滚动时标签保持在列表上方。核对搜索和类型组合筛选、新复制记录的类型匹配，以及“重置”恢复全部类型；用 Tab 和方向键切换标签。
